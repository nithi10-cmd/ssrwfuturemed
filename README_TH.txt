RehabGlove Clinic — คู่มือติดตั้ง
====================================

ไฟล์ในโฟลเดอร์นี้
  RehabGlove.bat          เปิดแอป (หน้าต่างแอป + โปรแกรมอ่านบัตรประชาชน)
  create_shortcut.bat     สร้างไอคอน "RehabGlove Clinic" บนเดสก์ท็อปและเมนู Start
  build_exe.bat           (ไม่บังคับ) สร้าง RehabGlove.exe ไว้ใช้กับเครื่องที่ไม่มี Python
  thai_id_bridge.py       โปรแกรมหลัก
  app.ico                 ไอคอนแอป
  web\                    หน้าแอป (ใช้ทั้งบน Windows และอัปโหลดขึ้นเว็บสำหรับ Android)
  web\ocr\               ตัวอ่านภาพบัตร (Tesseract.js, Apache-2.0) และข้อมูลภาษาไทย/อังกฤษ
  rehab_glove_kmatrix_ble_v3.ino   โค้ด Arduino ของถุงมือ

----------------------------------------------------------------
แอปบน Windows
----------------------------------------------------------------
ต้องมี: Python (ติ๊ก "Add python.exe to PATH" ตอนติดตั้ง) และ Chrome หรือ Edge

1. แตกไฟล์ zip ไว้ในโฟลเดอร์ที่จะใช้ประจำ (อย่าย้ายโฟลเดอร์ภายหลัง เพราะไอคอนจะหาไฟล์ไม่เจอ)
2. ดับเบิลคลิก create_shortcut.bat  -> ได้ไอคอน "RehabGlove Clinic" บนเดสก์ท็อป
3. ดับเบิลคลิกไอคอนนั้น -> แอปเปิดเป็นหน้าต่างของตัวเอง
   * จะมีหน้าต่างดำย่ออยู่ที่แถบงาน = ตัวโปรแกรม ปิดหน้าต่างดำนั้นเมื่อเลิกใช้งาน
   * เปิดไอคอนซ้ำได้ ระบบจะเปิดหน้าแอปเพิ่มโดยใช้โปรแกรมตัวเดิม

(ไม่บังคับ) ทำเป็นไฟล์ .exe:
   ดับเบิลคลิก build_exe.bat -> ได้ไฟล์ dist\RehabGlove.exe ไปใช้เครื่องอื่นได้โดยไม่ต้องลง Python
   ถ้าสร้างไม่สำเร็จบน Python รุ่นใหม่มาก (เช่น 3.15) ให้ติดตั้ง Python 3.13 แล้วลองใหม่

⚠️ ย้ายข้อมูลเดิม: ข้อมูลที่บันทึกตอนเปิดไฟล์ .html ตรงๆ จะไม่ปรากฏในแอป (เบราว์เซอร์แยกเก็บตามที่อยู่หน้าเว็บ)
   เปิดไฟล์ .html เดิม -> ทะเบียนผู้ป่วย -> "สำรองข้อมูล" แล้วไปกด "นำเข้าข้อมูล" ในแอป

----------------------------------------------------------------
แอปบนมือถือ Android
----------------------------------------------------------------
มือถือต้องเปิดแอปจากเว็บที่เป็น HTTPS จึงต้องอัปโหลดโฟลเดอร์ web ขึ้นเว็บฟรีก่อน (ทำครั้งเดียว)

1. อัปโหลด (เลือกวิธีใดวิธีหนึ่ง)
   ก. Netlify Drop (ง่ายที่สุด): เปิด https://app.netlify.com/drop แล้วลากโฟลเดอร์ "web" ไปวาง
      -> ได้ที่อยู่เว็บแบบ https://xxxx.netlify.app  (สมัครบัญชีฟรี เพื่อไม่ให้เว็บถูกลบ)
   ข. GitHub Pages: สร้าง repository แล้วอัปโหลดไฟล์ในโฟลเดอร์ web -> Settings -> Pages
2. บนมือถือ Android เปิดที่อยู่เว็บนั้นด้วย Chrome -> เมนู ⋮ -> "ติดตั้งแอป" (หรือ "เพิ่มลงในหน้าจอหลัก")
   -> ได้ไอคอน RehabGlove บนหน้าจอ เปิดแล้วเต็มจอเหมือนแอปทั่วไป และเปิดได้แม้ไม่มีเน็ต
3. เปิด Bluetooth และตำแหน่ง (Location) ของมือถือ ก่อนกด "เชื่อมต่อ" ถุงมือ

(ไม่บังคับ) ทำเป็นไฟล์ .apk:
   เปิด https://www.pwabuilder.com ใส่ที่อยู่เว็บจากข้อ 1 -> Package for stores -> Android -> ดาวน์โหลด
   แล้วติดตั้งไฟล์ .apk บนมือถือ (ต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")
   หมายเหตุ: แอป .apk แบบนี้ยังโหลดหน้าแอปจากเว็บในข้อ 1 จึงต้องไม่ลบเว็บนั้น

ลงทะเบียนด้วยการถ่ายรูปบัตรประชาชน (มือถือ / แท็บเล็ต / คอมพิวเตอร์)
   หน้า "ทะเบียนผู้ป่วย" -> "ถ่ายรูปบัตร" (หรือ "เลือกรูปจากเครื่อง")
   * อ่านข้อมูลด้วย OCR ในเครื่องเอง รูปบัตรไม่ถูกส่งขึ้นอินเทอร์เน็ต และไม่ถูกบันทึก
   * ระบบเปิดฟอร์มพร้อมข้อมูลและรูปบัตร ให้ตรวจทุกช่องเทียบกับบัตรก่อนกดบันทึก
     (ชื่อ-นามสกุลภาษาไทยอาจขาดสระ/วรรณยุกต์บางตัว)
   * เลขบัตรถูกตรวจด้วยหลักตรวจสอบ ถ้าอ่านผิดระบบจะแจ้งและไม่ให้บันทึกจนกว่าจะแก้
   * ถ้าเลขบัตรตรงกับผู้ป่วยในทะเบียน ระบบจะถามก่อนเลือกผู้ป่วยรายนั้น
   * ใช้ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอ่านภาพ (~12 MB) ครั้งต่อไปใช้แบบออฟไลน์ได้
   * เคล็ดลับ: วางบัตรบนพื้นสีเข้ม ถ่ายให้บัตรเต็มภาพ ไม่มีแสงสะท้อน

ข้อจำกัดบนมือถือ
   * เสียบเครื่องอ่านบัตรประชาชนไม่ได้ ให้ใช้การถ่ายรูปบัตร หรือกรอกข้อมูลเอง
   * iPhone ใช้ควบคุมถุงมือไม่ได้ (Safari ไม่รองรับ Web Bluetooth)
   * ข้อมูลบนมือถือแยกจากคอมพิวเตอร์ ย้ายข้อมูลด้วย "สำรองข้อมูล" / "นำเข้าข้อมูล"

เมื่อแก้ไฟล์ในโฟลเดอร์ web แล้วอัปโหลดใหม่ ให้เปลี่ยนเลข VERSION ใน web\sw.js
(เช่น rehabglove-v2 -> rehabglove-v3) เพื่อให้มือถือที่ติดตั้งแล้วโหลดไฟล์ใหม่
